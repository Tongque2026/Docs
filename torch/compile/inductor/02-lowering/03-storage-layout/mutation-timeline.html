old=x+1；x.copy_(y)：两个值版本、两份存储

条件：x、y 均为连续 CPU float32[3]。每个元素 4 byte。地址用“x+0、x+4、x+8”和“old+0、old+4、old+8”表示两块独立存储中的 byte 偏移，不代表实验进程的绝对地址。

阶段 0：调用者的 x 仍保存旧值

存储身份x+0x+4x+8
输入 x（旧版本）x[0]=0x[1]=1x[2]=2

阶段 1：先从旧 x 产生独立 old buffer

存储身份槽位 0槽位 1槽位 2是否与 x 同址
x 仍未覆盖x+0 → 0x+4 → 1x+8 → 2就是调用者 x
buf0 / oldold+0 → 1old+4 → 2old+8 → 3否，独立分配

阶段 2：把 y 写回同一个 x storage

存储身份槽位 0槽位 1槽位 2返回关系
输入 x（新版本）x+0 → 9x+4 → 9x+8 → 9returned_x 与调用者 x 同一 data_ptr
buf0 / oldold+0 → 1old+4 → 2old+8 → 3仍保留覆盖前计算结果

正确顺序：read old x → store old buffer → write y into x。若先覆盖 x，old 将错误地变成 [10,10,10]。

当前实验生成的一个 C++ function 内有两个循环：第一个循环读取 x 并写 old；第二个循环读取 y 并写 x。kernel 融合没有取消两个数据版本，也没有让 old 与 x 共享存储。
